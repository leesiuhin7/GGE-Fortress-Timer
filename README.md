# GGE Fortress Timer

A Rust application for tracking attack timers of fortesses in GGE.

## Getting Started

### Prerequisites

- Rust toolchain

### Installing

1. Clone the repository
```sh
git clone https://github.com/leesiuhin7/GGE-Fortress-Timer.git
```
2. Build the application
```sh
cargo build
```
3. Run the application
```sh
cargo run
```
